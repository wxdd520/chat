# 🔐 密聊 · 密码配对聊天

一个轻量级的实时加密聊天应用。无需注册、无需服务器，输入相同的「房间密码」即可开始聊天。

## ✨ 特性

- **零门槛聊天** — 不需要注册账号，输入昵称和房间密码就能用
- **密码配对** — 你和对方输入相同的密码即可自动进入同一房间
- **实时通信** — 基于 MQTT 协议，消息实时送达
- **支持图片** — 可以发送图片，支持点击放大预览
- **表情面板** — 内置丰富的 Emoji 表情分类
- **输入提示** — 对方正在输入时实时显示
- **在线状态** — 自动检测对方在线/离线状态
- **暗色主题** — 护眼的深色 UI 设计
- **响应式布局** — 手机、平板、电脑都能用
- **全球可用** — 使用公共 MQTT 中转，任何网络都能连（无需梯子）

## 🚀 在线体验

直接打开 `index.html` 即可使用，或者访问部署地址：

> https://wxdd520.github.io/chat

**使用方法：**
1. 打开网页，输入你的昵称
2. 和对方约定一个相同的房间密码
3. 输入密码，点击「进入房间」
4. 开始聊天！

## 🛠️ 技术栈

| 技术 | 说明 |
|------|------|
| HTML/CSS/JS | 纯前端，无需后端服务 |
| [MQTT.js](https://github.com/mqttjs/MQTT.js) | 基于 MQTT 协议的实时通信 |
| [EMQX](https://www.emqx.com/) | 公共 MQTT Broker（wss://broker.emqx.io:8084/mqtt） |
| Web Crypto | 用于房间密码的哈希配对 |

## ⚠️ 注意事项

- 使用的是 EMQX 公共 MQTT Broker，适合轻量个人使用，不建议传输敏感信息
- 图片以 Base64 格式通过 MQTT 传输，建议单张图片不超过 10MB
- 公共 Broker 可能有并发限制，高频使用建议自建 MQTT 服务
- 消息不会持久化存储，刷新页面后聊天记录清空
